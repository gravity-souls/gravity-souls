# 聊天分享卡片发布与验收

## 完整链路

聊天分享入口 → 星球／星系／活动分类与名称搜索 → 选择 → 明确发送 → 对方未读与
站内消息通知 → 动态卡片 → 原目标页 → 返回聊天。选择／查看不会发送、关注、加入
或报名。失败保留选择与原发送键，重复尝试不新增消息或通知。

只存类型和稳定目标 ID，不存名称／头像／会议信息快照。服务端选择和新发送均检查
双方权限；消息读取按当前查看者权限生成卡片。不可用卡片不返回目标 ID、名称、
图片或 URL。头像使用真实当前定制配置；星系改 slug 不破坏消息；已删目标仍保留
消息占位。事件卡片不含 onlineUrl、名单、审批原因等受限数据。

星系目录名称可由登录用户查看，APPROVAL 加入规则不让目录信息变成私密；活动
沿用详情权限，成员看 APPROVED/PASSED/CANCELLED，管理员／操作员／组织者例外，
仍受组织者有效状态和双向屏蔽限制。星球需要活跃、有效账号及 canViewProfile。

收件列表使用三语通用“分享了一张卡片”，通知沿用普通新消息提示，不包含目标名称。
导出仅含本人会话里的标量引用。沿用现有账号删除的匿名化历史规则，删除参与者后
聊天只读，不新创数据保留政策；删除星球／目标账号使引用不可用。

## 同步与性能边界

最新消息每 10 秒／重新聚焦时读取。已加载的旧卡片每批最多 100 个消息 ID 重新验证，
并替换旧展示；复查失败时隐藏旧卡片元数据。它不是实时推送撤销，也不能让已经
收到内容的人忘记信息。每次服务器读取按权限重新生成；目标页还会重新授权。

选择器每页扫描 20 个候选，隐藏双方不可访问的结果；分页位置为数字，避免通过
游标返回隐藏目标 ID。隐藏候选可能导致本页无结果但仍可“查看更多”。最多扫描
到 10000 的分页位置；偏移分页在目录变化时可能遗漏候选，重新搜索可刷新，客户端
按 ID 去重。同一批消息的重复引用只解析一次，不宣称所有不同目标均为批量 SQL。
