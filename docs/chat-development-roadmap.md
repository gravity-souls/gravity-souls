# 聊天链路开发路线

2026-10-05，按用户补充需求记录。当前实际支持：文字及系统键盘 Emoji、发送失败保留
草稿和幂等重试、历史分页、已读和站内通知。尚无图片／附件、表情选择器／回应、
可点击链接／预览卡片、结构化分享卡片或浏览器／手机系统推送。

## 执行顺序

1. 光束邀请：未互关 → 明确发送邀请 → 收件列表／站内通知 → 接受或拒绝 →
   创建／复用会话 → 手动发送 → 已读／回复。与关注独立，不自动发第一条消息。
2. 文字体验：保留换行、三语输入提示、Emoji 选择器、仅允许安全 http/https 链接。
   再增加星球／星系／活动的站内分享卡片；接收者必须重新检查访问权限，隐藏目标不能
   因卡片、缩略图或链接预览曝光。外部网址预览需服务端 SSRF、重定向与私网防护后再做。
3. 私密图片：选择／拍摄 → 客户端预览 → 受限上传 → 可重试发送 → 两端展示／查看。
   必须先落实带鉴权的附件读取，文件大小／格式限制、失败清理与权限撤销；不可直接复用
   当前公开动态的分享式图片 URL 作为私聊附件。先做图片，再决定其他文件、语音、视频。
4. 会话操作：消息回应、引用回复、草稿与失败状态、多端同步；撤回／删除需先确定两端
   的具体语义和历史显示规则，不把客户端隐藏误当成服务端撤回。
5. 系统推送：明确用户主动授权、订阅／退订、锁屏内容偏好、未读去重和深链接。
   分别验收桌面浏览器与 iPhone/PWA 支持，区别站内通知与操作系统通知。

各阶段覆盖双账号、重复点击／断网重试、屏蔽／删除／私密变化、中英法和真实手机。
当前只开始第 1 阶段，后续内容为开发计划，未宣称已经实现或决定数据保留政策。
