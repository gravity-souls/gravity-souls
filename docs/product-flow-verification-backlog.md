## 1. 动态与活动

- 评估独立“活动”入口，复用现有活动页面；移动端避免直接增加拥挤的底部导航。
- 建议主要分区：发现活动、感兴趣、我的活动。我的活动区分已报名、待审核、我发起、历史。
- “感兴趣”是收藏，不代表报名，不占名额；可取消，需持久化并与报名状态并列展示。
- 发现活动区分可见性与报名资格，不能泄露未公开活动或绕过星系成员权限。
- 动态可选关联星系或活动；选择活动时自动确定所属星系，服务器校验权限及关联一致性。
- 关联卡片支持进入星系／活动；活动详情承接讨论和活动回顾。
- 现有 Post 与 CommunityPost 是独立模型，ADR 0001 已明确此点。是否调整模型、跨页面展示与互动归属需评估并记录新决策，不能无意合并或复制。
- 活动验收：发现 → 感兴趣／取消收藏 → 加入星系／审批 → 报名／审批 → 取消或活动结束 → 回顾。
- 动态验收：发布／媒体上传 → 可选关联 → 展示与权限 → 点赞／评论 → 各入口跳转 → 编辑／删除同步。
- 覆盖作者、普通成员、非成员、待审核成员、组织者、管理员；检查重复提交、容量、过期／取消活动和失效关联。

## 2. 消息与提示

本阶段已实施：对话与通知分页；消息读取和已读确认分开；仅确认已加载消息，保留同时新到消息；对话刷新、已读回执、草稿重试去重；未读更新事件；屏蔽和私密头像保护；注销账号历史只读；通知操作失败不伪更新；模板按收件人语言生成；通知入口区分会话与系统／互动提示。数据库验收及三语言检查见 `social-flow-development.md`。浏览器／线上验收待完成。

- 梳理私信、光束、系统通知、互动通知的真实数据来源、入口及权限，明确哪些仍为演示数据。
- 区分对话消息与系统／互动通知，统一未读数量及已读状态；沿用此前避免入口冗余的要求。
- 验收：触发动作 → 收件人收到消息／通知 → 未读数更新 → 点击进入正确对话／内容 → 标记已读 → 各入口与刷新后同步。
- 检查头像菜单、我的空间、消息列表、通知列表的跳转和状态一致性。
- 覆盖回复、删除／失效内容、分页／加载更多、空状态、请求失败、重复触发、跨账号隔离、屏蔽后的行为。
- 通知正文使用收件人语言；内容权限由目标接口再次校验，不能仅凭通知链接访问。

## 3. 发现星球、光束、轨道与关注

本阶段已实施并验证服务器路径：重复关注只写一次关系与通知；被屏蔽对象不进入关系列表；保存轨道严格校验、幂等及账号隔离，排除停用／私密／被屏蔽星球。光束当前是进入既有消息发送流程：新会话需互相关注，打开会话不自动发送。独立光束邀请机制尚未实现。发现列表和星球详情的真实多账号浏览器链路仍待验收。

- 评估“发现星球”独立栏目及与首页／共鸣／现有 discover 页的职责；此项尚未决定，不新增重复页面。
- 验收主线：发现／搜索／筛选 → 星球详情 → 发送光束、保存到轨道、关注 → 我的空间／轨道／消息中查看结果。
- 光束：真实发送和接收、状态反馈、收件通知、能否回复／进入对话、重复点击与失败重试；不能只播放动画或使用模拟消息。
- 轨道：保存／移除、持久化、各入口同步、列表及详情跳转、重复保存幂等。
- 关注：关注／取消、关注关系与列表同步、通知、重复操作幂等；与“保存到轨道”明确区分。
- 检查自身星球、私密／屏蔽／删除／停用星球、未登录用户、重复请求及权限变更。
- 首页、发现、共鸣、轨道、关注、消息中的星球均使用相同定制头像及可见性规则。

## 4. 星图探索

已实现：`/star-map` 的发现／星系／共鸣三个模式，真实数据与定制头像；粒子只作装饰、连线只作探索引导；滚轮／双指缩放、分层进入、旋转、返回状态保存、键盘／列表替代；每批最多 36 星球／24 星系，最多 2,000 装饰粒子；移除暂停、刷新和缩放按钮。桌面导航与三个板块已有入口。系统减少动态效果仍生效。

共鸣复用现有六种推荐原因与颜色，分数仅对本批次推荐排序；发现按自填气候，星系按真实社区分组。首版定义、规模限制和已通过测试见 `star-map-production.md`。MR #23 已合并，但未确认部署，触控、视觉、性能与完整返回闭环尚未完成浏览器验收。

- 用户反馈：星图仍是一条不明显的链路，需要充分完善；不仅验收视觉，还需明确入口、用途、可操作对象和后续动作。
- 先核查用户所指星图与现有 ResonanceMap、cosmic-globe、my-universe、create-universe 的对应关系；不默认它们是同一个功能，不新增重复入口。
- 明确星图与“发现星球”“共鸣”“我的宇宙”的职责、命名和入口，首次进入需能理解如何探索。
- 验收主线：找到入口 → 加载真实星球／星系 → 搜索／筛选／移动／缩放 → 选中对象 → 预览 → 星球或星系详情 → 光束／保存轨道／关注或加入星系 → 返回原视角与筛选状态。
- 区分星球、星系、自身、已保存、已关注对象及关系，提供易理解的图例／提示，避免再引入此前要求移除的突兀圆环和边缘线。
- 验证预览与实际对象对应、定制头像一致、点击命中、遮挡／重叠、标题和操作按钮可读。
- 检查是否使用真实数据，数据量较大时的加载与性能、空／失败状态、重试及重复加载。
- 覆盖移动端触控、桌面鼠标、键盘操作及无需三维操作的列表替代入口，避免探索功能只能依赖复杂手势。
- 校验私密、屏蔽、删除／停用对象的可见性；搜索、预览、详情和通知不能绕过权限。
- 若星图包含“创建宇宙”，单独验证创建 → 持久化 → 我的宇宙展示 → 再次进入／管理，并明确与星系创建的区别。
- 验收跨页面返回后对象、位置、筛选和互动状态是否一致；检查中英法文案及加载提示。
