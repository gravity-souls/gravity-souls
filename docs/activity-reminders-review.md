# 活动提醒与历史状态

与 MR46 的光束、关注、轨道同步放在同一个合并请求中。用户已授权检查通过后一起合并。

## 提醒与权限

- 活动详情增加用户主动点击的日历文件导出，包含 UTC 开始时间和提前 15 分钟的日历提醒。下载后仍需在日历中确认导入和提醒设置；下载成功不表示提醒已开启。
- 只允许活动组织者或已批准报名者导出。每次下载重新验证登录、用户未删除、当前星系访问权限、双向屏蔽、组织者未删除、活动已批准且开始时间未过。待审核、拒绝、撤销的报名不允许导出。
- 文件仅含标题、时间和地点，不包含会议链接、描述、参与者名单或账号信息。文本转义并按 UTF-8 字节折行，标题不能注入第二个事件。
- 日历文件是副本，不是订阅。改期、取消或退出报名后需用户自行更新／删除副本；页面明确说明这一点。日历软件是否保留、触发提醒由其设置决定。

## 即将开始与历史展示

- 首页和个人星球页优先展示已批准报名的未来活动，再补充所在星系的推荐活动。待审核、拒绝、撤销报名不作为推荐重新出现。只有确认报名的活动带提醒状态，24 小时内开始与其他未来活动区分。
- 即将开始接口补上退出星系、组织者删除、双向屏蔽和用户删除检查。推荐卡片不返回私密会议链接或不可见的组织者头像；空结果始终返回 `event: null, events: []`。查询严格验证，结果不缓存，也不修改全局活动状态。
- 首页和个人星球页在操作／站内消息、焦点和返回前台时刷新，并每分钟在前台重读。失败清除旧活动。读取序号阻止旧响应覆盖新结果。
- 卡片与详情在开始时间到达后关闭报名和日历导出入口，即使数据库状态尚未改为 PASSED。沿用产品现有开始时间作为历史分界，不推断真实结束时间或活动时长。
- 详情区分取消、开始时间已过、退出报名。历史活动与星群继续使用 MR45 已实现的历史层；失去访问权限仍由服务端隐藏。

- 167 项活动／关系／星图检查、24 项基础测试、71 项现有聊天回归通过（262 项）。
- 类型检查、变更文件 ESLint 零警告、生产 webpack 构建通过。全库 lint 通过，仍有原有的 16 项警告。
- 新真实 SQL 检查验证报名优先、审核／退出状态、24 小时提醒、无读取写入副作用、字段隐私、退出星系、双向屏蔽、删除、日历鉴权与状态撤销、UTC 时间、文本注入和 Unicode 折行。三语组件检查覆盖提醒入口与过期活动操作关闭。
- 新 Playwright 流程覆盖主动导出、失败重试、下载反馈和退出后的入口关闭，桌面、手机及 iPhone WebKit 共 3 项可发现。与上一轮相同，本地浏览器引擎缺失，页面、日历应用、双账号及真实手机验收未完成；远端 CI 结果单独核对。

无数据库迁移、定时服务或新环境配置。不实现后台站内开始通知、日历订阅同步或操作系统推送。聊天功能继续等待存储等配置完成后验收。合并不等于部署或线上验收通过。

## 合并前的既有浏览器用例校正

MR46 首次远端数据库浏览器检查报告 91 项通过、11 项失败。核对实现后修正旧断言：不存在／无权访问的事件和会话使用 404；显式清空匿名 API 请求上下文的认证状态；文字长度沿用已实现的 4000；共鸣节点沿用当前 Signal Score 标签，抽屉流程使用手机视口并将重复分数定位到可见对话框；全局 404 标题使用当前翻译。首页滚动流程创建并清理足够的真实星系记录，避免单个卡片时仍期待滚动按钮启用。保留各流程原有的授权、持久化、几何和键盘断言，不改业务行为或跳过检查。以上校正随同一 MR46 提交，远端重新验证。

公开页面演示用例不使用共享数据库，CI 将 desktop、mobile、iphone-safari 分别放到独立任务中运行；每个项目保持原有串行顺序、全部用例和失败重试，任一浏览器失败不会取消另两个项目。数据库套件仍保持原有串行流程。

第二轮真实数据库浏览器检查 97 项通过、5 项失败；进一步核对后保留会话 GET 隐藏为 404、POST 拒绝为 403 的不同语义。共鸣激活前通过真实键盘焦点暂停运动，保留正常 click 的可见性与可操作性检查，不使用强制点击。

最终同步补充：按钮的失败重试广播只读刷新请求，收藏页、个人星图、关注与邀请入口一起重新查询；即使之前写入已提交但响应失败，也不执行反向写入。浏览器用例同时检查真实轨道列表移除与写入次数保持一次。

手机回归发现动态页发布悬浮按钮与底部导航重叠，现按导航高度和安全区域留出间距。浏览器用例修正了导航搜索框与聊天输入框、背景画布与交互星图画布的区分，活动详情模拟覆盖子路径，错误提示排除 Next 路由播报器；星图页面移除嵌套 main 地标。所有项目仍完整运行，未跳过失败用例。

远端后续回归确认完整桌面数据库套件 102 项通过。活动详情失权时的提示原先会被同时完成的列表刷新清除，现将详情读取错误与列表错误分别保存，保留失权反馈并立即移除详情。触摸端发送失败用例使用现有发送按钮，星图滚轮用例先将交互画布滚入视口。登录引导分支和注册复用已有会话可读检查，确认会话后再调用需要登录的后续接口；浏览器导航等待 DOM 就绪，数据库持久化断言保留。CI 失败时保存隔离测试数据的轨迹和截图，供继续核对。
