# 光束、轨道与关注状态同步

本轮在已合并的 MR45 上补齐社交入口状态，不涉及聊天存储配置或新消息功能。

## 行为

- 关注、取消关注、收藏和取消收藏提供中英法成功提示。读写失败后清除无法确认的按钮状态；重试先 GET 最新状态，不把可能已经成功的操作反向执行。
- 新增鉴权只读 `/api/beam-invitations/status?recipientId=…`，返回当前用户自己的邀请状态、是否有待回应的来信及可见会话 ID。复用双向联系权限，屏蔽、删除或不可见时不返回邀请和会话信息。拒绝调用者指定 owner 等额外查询字段。
- 邀请入口展示待回应、接受、拒绝、取消；待回应可取消，终态不可重发。收到来信引导至收到的邀请。发现已有会话展示继续聊天入口；刷新不会自行跳转。
- 收藏页、关系页、个人星图及社交按钮在同页面操作事件、站内消息事件、窗口焦点和重新进入前台时读取服务器状态。邀请列表保留已有 20 秒前台轮询。此机制不保证后台标签页或跨设备实时推送。
- 操作前使旧读取失效，操作期间不发起覆盖状态的刷新。读取失败时清除旧列表，避免继续展示无法确认权限的数据。

- `npm run typecheck`、变更文件 ESLint 零警告及生产 `next build --webpack` 通过。
- 新服务端用例覆盖认证、状态读取、双方邀请方向、接受后的会话、取消、无写入副作用、额外参数、双向屏蔽和删除。
- `beam-invitations.spec.ts` 共 4 个流程，桌面、Android 视口和 iPhone WebKit 合计 12 项可发现。新增前台读取已接受邀请但不跳转／写入，以及删除已提交但响应失败时重试只读取的流程。
