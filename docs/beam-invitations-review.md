# 光束邀请发布与验收

## 行为

非互关的光束入口提供明确邀请操作。发送者查看／取消，接收者接受／拒绝。
接受创建或复用会话，不创建关注、消息或奖励。同一方向拒绝／取消后不再邀请；
重复发送不新增通知或消耗额度。反向待处理邀请引导查看收件列表，不自动接受。
每人固定 24 小时窗口最多五次新邀请。所有入口保留允许的探索返回来源。

双方须为有效账号且可相互查看与联系。双向屏蔽或失去可见性隐藏邀请并阻止接受。
通知使用接收者语言并与消息未读分开。账号导出包含本人参与的邀请标量记录；
自助删除清理双方相关邀请。列表每页最多 20 条，定时刷新返回最新第一页；
通知定位仅高亮当前已加载的邀请，不保证自动遍历旧页。

## 验证边界

隔离 PGlite 数据库执行真实迁移与 Prisma 路由；只替换登录身份。覆盖重复发送、
身份越权、接受／拒绝／取消、私密／屏蔽、限额、分页、三语通知、真实定制头像、
导出和删除，以及接受后零消息／零关注。组件测试覆盖中英法与角色操作差异。
PGlite 连接序列化，不能证明真实多连接 PostgreSQL 的并发竞争。

Playwright 增加显式发送、取消失败重试和接受不自动发送的模拟交互规范。
浏览器规范的发现检查不等于执行；浏览器引擎与真实双账号／iPhone 验收仍待完成。

## 发布与回退

新增 `20261005010000_add_beam_invitations`：邀请表、状态枚举、两个通知类型、
唯一约束、列表索引与外键。无回填、无破坏性修改。发布环境必须先运行正常的
`prisma migrate deploy`，再启用新应用；本轮未连接生产库或运行线上迁移。
回退应用版本时保留新增表和枚举，避免删除已产生邀请数据。

部署后用两账号验证站内通知深链、接受后空会话、手动发送／已读／回复、
拒绝／取消、屏蔽隐藏、头像和语言、手机布局与返回星图。另用隔离 PostgreSQL
多连接验证接受／取消、创建／屏蔽、创建／删除竞态。
