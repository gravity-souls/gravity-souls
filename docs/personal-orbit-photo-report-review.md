# 个人收藏轨道、照片展示和独立匹配报告

2026-10-05，接续 MR47。用户反馈收藏成功但看不到轨道，上传手机照片被变形成自旋 3D 星球，匹配报告没有独立页面。

## 收藏轨道

原“查看已保存轨道”指向 `/saved` 收藏列表，现直达 `/star-map?mode=personal&collection=saved`，同时保留单独收藏列表入口，列表也提供星图入口。个人星图进入分组后不再隐藏自身节点和真实关系线；个人分组只筛选数据，保持自身星球居中，不沿用发现模式的自动放大。收藏金色虚线增强可见度；关注和互关保持各自箭头及图例，不把收藏说成关注。只有服务端实际返回、访问获准的关系绘制连线，分页／搜索及私密限制保持既有规则。

## 平面预览与照片

PlanetGlobe 的既有调用位置统一使用 PlanetAvatar 轻量圆形图片，不再创建 WebGL 球体，覆盖个人主页、定制预览、导航及星球详情。上传照片即使旧配置带自旋和云层参数，也始终静态 object-cover 显示，不叠加球面高光、阴影或云层；其他共鸣头像和卡片采用同一规则。圆形裁切可能截去照片边缘，本轮不新增裁切编辑器。

定制界面移除自旋速度控制，上传“纹理”改称照片；照片模式隐藏不适用的云层控制，预设图片仍可选择云层。颜色／光晕及强度可继续调整，预览和保存后使用同一展示组件。旧配置字段兼容保留，不需要数据库迁移，不更改已上传文件或 URL。独立宇宙探索场景的 3D 导览不在此轮改动范围内。

## 独立报告

`/my-planet/report` 不再重定向到个人主页。新页面有单独标题、返回入口、概览、刷新操作及每个匹配的分数／维度／共同点／差异和星球／联系入口，个人主页和共鸣详情均可进入。读取当前账号现有鉴权接口，使用共鸣同一 `buildResonanceSession` 算法和当前候选批次，最多五个匹配；明确显示批次范围，不把 XP 或收藏数冒充匹配结果，也不代表心理诊断、确定兼容性或实际关注关系。

报告以中英法显示。初始化、刷新、窗口聚焦／返回前台、社交变更时重新读取；请求被替换时中止旧请求，不把已撤销的候选保留在加载／错误界面。未登录、无星球、空候选、网络失败分别展示可继续操作的状态。它是当前结果的动态页面，不创建历史报告快照或公开分享链接。

## 验证边界

既有单元测试、星图数据库与 UI 测试继续运行，新增照片静态展示及三语报告分数／空态测试。浏览器场景检查独立 URL、照片、权限失效清空、手机溢出，以及个人分组继续绘制金色收藏线。本地浏览器引擎下载不可用，实际浏览器矩阵交远端 CI；不将 SSR 结果称为真实手机验收。部署后仍需用真实照片和收藏账号检查图片裁切、定制保存与头像同步、轨道点击及报告返回。
