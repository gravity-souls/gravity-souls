# 聊天文字体验发布与验收

## 本轮实现

常用 20 个 Emoji，三语标签、键盘关闭、选区替换和光标恢复。文本框随内容增高，
限高后滚动；小屏表情区限高，按钮适合触摸。消息保留内部换行，长网址折行。
桌面精细指针支持 Enter 发送／Shift+Enter 换行，触屏回车换行、按钮发送，
输入法合成 Enter 不发送。选择表情不会发送；失败保留草稿和已有幂等重试键。

消息仍为纯文字。只将显式 http/https 网址展示为链接，拒绝 URL 凭据、控制字符、
反斜线和危险协议嵌套；HTML 始终按文字转义。链接使用新标签页及 noopener/noreferrer，
不自动请求外部预览或下载目标内容。不将普通 URL 自动转换为权限敏感的内部卡片。
计数与既有服务器规则一致，按 Unicode 码点计算，最大 2000。星球 Emoji 算 1，
组合 Emoji 可能包含多个码点。粘贴截取按码点进行，不截断 UTF-16 代理对；
DOM 光标／选区偏移仍按 UTF-16 单位恢复。

## 验证

`npm run test:chat` 验证网址识别、危险输入转义、标点／中文、Emoji 选区与边界、
三语实际组件输出。`npm run test:galaxy` 新增真实迁移数据库路由测试，验证 Emoji、
换行与网址在收发和重试后保持原文、重复发送只产生一条消息／通知，以及长度边界。

`e2e/demo/chat-content.spec.ts` 共 4 个场景 × 3 个浏览器配置：三语输入、插入、
失败重试键、重新载入后的链接、多行、IME、桌面／触屏发送、长度上限和只读会话。
尝试安装 Chromium 时下载包无效，浏览器交互尚未执行；发现检查不等于执行通过。
真实双账号、实际 iPhone 键盘／软键盘遮挡和 Safari 视觉检查仍待部署后验收。

验证结果：8 项聊天安全／组件测试、89 项工作流数据库／组件测试、24 项基础测试通过；
三语键一致性、变更 ESLint、类型检查和生产构建通过。12 项 Playwright 规范仅完成发现检查。
